# 삼락교회 디자인 아카이브

교회 공동체의 예배와 행사, 다음 세대의 사역을 위해 제작한 시각 디자인 작업을 연도별로 정리한 포트폴리오입니다.

온라인 화면부터 인쇄물과 대형 출력물까지, 각각의 메시지와 사용 환경에 맞는 디자인을 기록합니다.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 프로젝트 | 삼락교회 시각 디자인 작업 아카이브 |
| 작업 기간 | 2023–2026 |
| 작업 범위 | 행사 홍보물, 예배·절기 디자인, 다음 세대 콘텐츠, 캐릭터·일러스트, 인쇄·출력물 |
| 정리 방식 | 연도별 폴더 및 프로젝트별 산출물 |

## 작업 범위

### 행사와 캠페인

교회 행사와 계절별 프로그램의 성격을 시각 언어로 정리하고, 포스터와 현수막, 배너, 썸네일 등 여러 매체에 맞게 확장했습니다.

- 수련회와 체육대회
- 바자회와 지역·선교 행사
- 특새, 절기 예배, 초청 행사
- 청년부 및 부서별 프로그램

### 예배와 절기

예배의 주제와 분위기를 전달하는 홍보물과 공간 출력물을 제작했습니다.

- 성탄, 부활, 어린이주일, 어버이주일
- 맥추감사절과 추수 관련 예배
- 분기별 예배·사역 안내
- 본당, 로비, 자모실 등 공간별 출력물

### 다음 세대 콘텐츠

어린이와 청소년이 친근하게 접근할 수 있도록 캐릭터와 일러스트를 활용한 콘텐츠를 기획하고 제작했습니다.

- 초등부 겨울·여름 프로그램 캐릭터
- 카툰 및 성경 관련 일러스트
- 중·고등부 수련회 홍보물
- 청년부 가이드북과 프로그램 콘텐츠

### 매체 확장

하나의 디자인을 매체별 비율과 제작 환경에 맞춰 재구성했습니다.

- 포스터 및 엽서
- 유튜브 썸네일과 디지털 홍보 이미지
- 현수막, 배너, 포맥스, 유리문 출력물
- 안내문, 미니맵, 스티커, 가이드북

## 폴더 안내

```text

├── 2023/   # 캐릭터, 카툰, 일러스트 중심 작업
├── 2024/   # 체육대회, 성탄 등 행사·절기 작업
├── 2025/   # 예배, 수련회, 행사 홍보물과 인쇄물
├── 2026/   # 예배·행사·월별 콘텐츠 및 공간 출력물

```

## 작업 방향

교회 디자인은 예쁜 이미지를 만드는 데서 끝나지 않습니다. 누구를 위한 행사인지, 어디에서 보게 되는지, 어떤 행동으로 이어져야 하는지를 먼저 살핀 뒤 메시지와 형태를 정리합니다.

작은 모바일 이미지부터 멀리서 읽어야 하는 대형 현수막까지, 매체의 거리와 크기가 달라져도 핵심 메시지가 유지되도록 작업했습니다.
