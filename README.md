# Church Design Archive ㅡ HYE!N

교회 디자인 작업을 기록한 개인 포트폴리오 아카이브입니다.

예배와 절기, 수련회와 캠페인, 부서별 프로그램처럼 교회 안에서 이루어지는 다양한 활동을 시각 언어로 풀어냈습니다. 온라인 이미지부터 인쇄물과 대형 출력물까지, 실제 사용 환경을 고려해 하나의 메시지를 여러 매체로 확장한 작업을 담고 있습니다.

교회 디자인은 단순히 보기 좋은 이미지를 만드는 일과 조금 다릅니다. 행사의 목적과 대상, 전달해야 할 메시지, 디자인이 사용될 공간과 매체를 함께 고려해야 합니다. 이 아카이브는 그 고민과 과정을 시각적으로 정리한 기록입니다.

## 작업 범위

- 행사와 예배를 알리는 포스터와 배너
- 현수막, 포맥스, 유리문 등 공간 출력물
- 유튜브 썸네일과 온라인 홍보 이미지
- 주보, 엽서, 안내문, 미니맵, 스티커
- 어린이와 청소년을 위한 캐릭터 및 일러스트
- 수련회 가이드북과 프로그램 콘텐츠

## 작업 과정

### 1. 목적과 대상 파악

행사의 성격과 핵심 메시지, 참여 대상과 사용 환경을 먼저 확인합니다. 같은 행사라도 어린이를 위한 프로그램인지, 청년을 위한 예배인지에 따라 정보의 우선순위와 시각적 분위기가 달라집니다.

### 2. 메시지와 분위기 정리

행사명과 일정 같은 필수 정보를 분명하게 정리하고, 행사가 가진 분위기와 주제를 색상, 이미지, 일러스트, 타이포그래피로 구체화합니다.

### 3. 매체에 맞는 디자인 제작

포스터와 모바일 이미지, 유튜브 썸네일, 현수막과 공간 출력물은 보는 거리와 비율이 모두 다릅니다. 하나의 디자인을 그대로 복사하기보다 각 매체에서 정보가 잘 읽히도록 레이아웃과 요소를 조정합니다.

### 4. 실제 사용 환경 확인

디자인이 화면 안에서만 완성되는 것이 아니라 실제 공간에 설치되고 사람들에게 보여지는 결과물이라는 점을 중요하게 생각합니다. 출력 크기와 설치 위치, 가독성, 주변 환경을 확인하며 최종 결과물을 다듬습니다.

## 작업의 방향

교회 디자인의 목적은 공동체가 전달하고 싶은 메시지를 사람들이 쉽게 이해하고 기억하도록 돕는 데 있습니다.

행사의 성격에 맞는 친근한 표현을 사용하면서도 날짜와 장소처럼 중요한 정보는 분명하게 전달되도록 구성했습니다. 디지털 이미지부터 대형 출력물까지 매체가 달라져도 하나의 메시지가 자연스럽게 이어지도록 확장하는 것을 중요하게 생각합니다.
